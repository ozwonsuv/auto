# Static Workspace

브라우저에서 실행되는 개인용 정적 작업 페이지입니다. 서버, 데이터베이스 또는 유료 기능이 필요하지 않습니다.

외부 데이터가 브라우저 접근을 제한하는 경우를 대비해 GitHub Actions가 검증된 최신 응답을 같은 GitHub Pages 주소에 정적으로 동기화합니다.

## 사용 방법

1. 웹페이지에서 생성 버튼을 누릅니다.
2. 원격 데이터가 준비되면 결과 미리보기가 열립니다.
3. 제목 또는 서식이 포함된 본문을 클립보드로 복사합니다.

페이지는 외부 사이트에 직접 내용을 등록하지 않으며 클립보드 복사까지만 수행합니다.

## 로컬 실행

저장소 루트에서 다음 명령을 실행한 뒤 `http://127.0.0.1:8765/`에 접속합니다.

```powershell
pwsh -NoProfile -File .\tools\Serve-Workspace.ps1
```
