# RDRG TTS PROGRAM Lite v1.0

한국어 문장과 선택한 음악 앱의 소리를 게임 마이크로 보내는 가벼운 Windows 프로그램입니다.

**[EXE 바로 다운로드](https://github.com/ozwonsuv/auto/raw/refs/heads/main/rdrg-tts/RdrgNativeTts.exe)**

`RdrgNativeTts.exe` 한 파일을 받아 실행합니다. 별도 앱 설치, .NET, Python, 브라우저 런타임, 음성 모델 다운로드는 필요하지 않습니다. 내장 음성 모듈과 설정은 Windows 사용자 데이터 폴더에 자동으로 준비됩니다.

## 사용 환경

- Windows 11 x64, 인터넷 연결. 입력한 문장은 Microsoft Edge 온라인 음성 서비스로 전송됩니다.
- 게임 마이크 송출에는 **VB-Audio VB-CABLE 기본 장치**가 별도로 필요합니다. 이미 설치되어 있다면 다시 설치하지 않습니다.
- 게임 마이크 입력은 **CABLE Output**, 게임 소리 출력은 실제 헤드셋/스피커로 선택합니다. 이 앱의 게임 송출 장치는 **CABLE Input**입니다.
- Windows 기본 소리나 다른 앱의 출력은 실제 헤드셋/스피커로 두세요. 케이블로 직접 보내는 다른 앱이 있으면 혼입을 막기 위해 이 앱의 송출을 차단합니다.

## 사용법

1. EXE를 실행하고 설정에서 게임 송출 장치와 내가 듣는 장치를 선택합니다.
2. **송출 켜짐** 상태에서 문장을 입력하고 Enter 또는 파란 보내기 버튼을 누릅니다. 송출이 꺼져 있으면 내 장치에서 미리 듣습니다.
3. 음악을 보내려면 설정에서 음악 앱을 선택한 뒤 **음악 재생중**으로 켭니다. 브라우저 선택 시 같은 프로세스 트리의 다른 탭 소리도 포함될 수 있습니다.
4. `Ctrl+Shift+N`으로 입력창을 열거나 접습니다. 단축키는 변경할 수 있습니다. `Ctrl+Alt+Backspace`는 전체 정지입니다.

목소리, 속도, 톤, TTS·음악 음량(0~200%), 장치, 음악 앱, 테마와 단축키 설정은 다음 실행에도 유지됩니다. 상단 ‘작동중’은 앱의 가상 오디오 송출 경로 상태이며, 다른 플레이어가 실제로 들었는지 확인하는 표시는 아닙니다.

## 업데이트

실행 후 10초 뒤 작은 버전 파일을 한 번 확인합니다. 새 버전이 있을 때 **새 버전 받기**로 표시하며, 확인 실패는 입력이나 음성 사용을 막지 않습니다. 확인 후 연결과 작업 스레드를 해제하고 계속 감시하지 않습니다.

**사용법 및 업데이트** 메뉴에서 직접 확인하거나 내장 도움말을 볼 수 있습니다. 새 EXE를 받은 뒤 기존 앱을 상단 X로 완전히 종료하고 교체하세요. 자동 설치·자동 교체·자동 실행은 하지 않습니다. 사용자 폴더의 설정은 보존됩니다.

웹페이지나 게시글에는 위의 고정 EXE 링크를 사용하면 됩니다. 업데이트 이후에도 같은 주소를 유지합니다. 이 폴더의 `version.txt`와 `SHA256SUMS.txt`는 배포 확인용이며 사용자가 따로 받을 필요는 없습니다.
