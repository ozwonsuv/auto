프로그램의 사용법 버튼은 위 게시글로 바로 연결됩니다. 화면 이름은 RDRG TTS PROGRAM Lite이며 버전은 v1.5입니다.

v1.5에서는 14개 기본 목소리와 사용자 음성 설정 저장, 속도·톤·저음/고음 EQ 조절, 카탈로그 스타일 버튼 및 설정 화면 정렬을 반영했습니다. 일시적인 설정 파일 잠금에 대한 짧은 재시도와 저장 오류 표시의 복구도 보완했습니다.

로컬 미리 듣기가 가상 마이크 송출을 막지 않도록 분리하고, 장치 오류 시 선택했던 장치와 음악 앱에만 자동 재연결하도록 보완했습니다. 네트워크 취소, 빠른 켜기·끄기, 이전 작업의 뒤늦은 완료도 처리합니다. 중단된 문장은 자동 재전송하지 않습니다. 복구를 최대 3회 시도한 뒤에도 연결되지 않으면 장치를 확인하고 다시 켜세요. 게임 자체 음성 채팅 및 상대방 수신 상태는 게임에서 확인해야 합니다.

화면에는 v1.5로 표시합니다. 이전 1.10.0과의 업데이트 비교를 위해 내부 파일·업데이트 버전은 1.50.0입니다.

실행 후 작은 버전 파일을 한 번 확인하고, 새 버전이 있으면 표시합니다. 프로그램 안의 업데이트 버튼은 기존 RdrgNativeTts.exe 주소를 엽니다. 자동 설치나 실행 파일 교체는 하지 않습니다. 기존 앱을 상단 X로 종료한 뒤 새 EXE를 실행하세요. 사용자 폴더에 저장된 설정은 유지됩니다.

라이선스 전문과 음성 모듈 소스·빌드 및 교체 방법은 EXE에 포함되어 있으며 설정 하단에서 확인하거나 저장할 수 있습니다.

웹페이지의 다운로드 버튼에는 위 고정 주소를 사용하면 됩니다. version.txt와 SHA256SUMS.txt는 배포 확인용이며 따로 받을 필요는 없습니다.
